# Портфолио Даши

Сайт-портфолио для первого трудоустройства, стажировок и учебных возможностей.
Сделан по данным из `resume.md` и `portfolio-data.json`.

**Стиль:** 1 — Nordic Lagom Corporate Minimalism.
Спокойная светлая палитра, много свободного места, тонкие линии, лёгкие анимации.

---

## 1. Что лежит в папке

| Файл | Что это |
| --- | --- |
| `index.html` | Главная страница. Здесь весь текст сайта. |
| `style.css` | Внешний вид: цвета, сетка, мобильная версия. |
| `script.js` | Меню на телефоне, подсветка меню, плавное появление блоков. |
| `favicon.svg` | Маленькая иконка вкладки браузера. |
| `resume.md` | Резюме. Кнопка «Скачать резюме» ведёт на этот файл. |
| `portfolio-data.json` | Данные резюме в виде JSON. Сайт их не читает. |
| `README.md` | Эта инструкция. |

Сайт не использует React, сборщики, npm и сервер.
Нужен только браузер.

---

## 2. Как открыть сайт

**Самый простой способ**

1. Откройте папку проекта.
2. Дважды щёлкните `index.html`.
3. Сайт откроется в браузере.

**Способ с локальным сервером** (удобно для проверки ссылок)

1. Откройте терминал в папке проекта.
2. Введите:
   ```bash
   python3 -m http.server 8000
   ```
3. Откройте в браузере `http://localhost:8000`.
4. Чтобы остановить сервер, нажмите `Ctrl + C`.

## 3. Как менять текст

Почти весь текст находится в `index.html`.
Файл подписан комментариями:

- `<!-- Первый экран -->` — имя и кнопки;
- `<!-- 01. Обо мне -->` — текст о себе;
- `<!-- 02. Образование -->` — колледж и специальность;
- `<!-- 03. Навыки -->` — программы и навыки;
- `<!-- 04. Проекты -->` — три учебные работы;
- `<!-- 05. Достижения -->` — пока пустой раздел;
- `<!-- 06. Цели -->` — интересы и планы;
- `<!-- 07. Контакты -->` — здесь контактов нет.

Правило простое: меняйте только текст между тегами.
Например:

```html
<h3>План урока</h3>
```

Здесь можно заменить «План урока» на другой заголовок.

После правки нажмите `Ctrl + S` и обновите страницу в браузере (`F5`).

---

## 4. Как менять цвета

Все цвета собраны в начале `style.css`:

```css
:root {
  --milk: #F7F6F2;
  --sage: #E8EDE8;
  --graphite: #252B2B;
  --slate: #627C85;
}
```

Меняйте значения после двоеточия.
Не меняйте имена переменных — они используются по всему файлу.

## 5. Что здесь честно и чего нет

В портфолио только подтверждённые данные:

- три учебные работы: презентации, план урока, отчёт по практике;
- всё выполнено самостоятельно;
- конкурсов, олимпиад и волонтёрства пока не было — так и написано;
- командного опыта пока нет — так и написано;
- нет фотографии: вместо неё CSS-графика;
- нет выдуманных работодателей, цифр, наград и ссылок.

**Контакты не публикуются по решению автора.**
На сайте нет телефона, e-mail, мессенджеров, города, фамилии и соцсетей.
Если автор разрешит, контакты можно добавить в раздел `<!-- 07. Контакты -->`.

## 6. Доступность и удобство

- Сайт работает с клавиатуры: `Tab`, `Shift + Tab`, `Enter`, `Escape`.
- В начале страницы есть ссылка «Перейти к содержанию».
- У кнопок и ссылок видна рамка фокуса.
- Цвета текста проверены на контраст.
- На телефоне меню открывается кнопкой.
- Если в системе включено «уменьшение движения», анимации отключаются.
- Разметка семантическая: `header`, `main`, `section`, `article`, `footer`.

## 7. Проверка перед публикацией

Откройте сайт и проверьте:

1. Все пункты меню ведут в свои разделы.
2. Кнопка «Скачать резюме» открывает или скачивает `resume.md`.
3. На узком экране (например, 375 px) меню открывается и закрывается.
4. Сайт читается с клавиатуры.
5. В тексте нет лишних личных данных.

## 8. GitHub Pages: инструкция

Публикация не выполнена. Это только шаги на будущее.
Делайте их только с разрешения автора портфолио.

1. Войдите на GitHub.
2. Создайте новый репозиторий, например `portfolio`.
3. Загрузите файлы из этой папки в корень репозитория:
   `index.html`, `style.css`, `script.js`, `favicon.svg`, `resume.md`.
4. Откройте **Settings** → **Pages**.
5. В блоке **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку **main** и папку **/(root)**.
7. Нажмите **Save**.
8. Подождите 1–2 минуты.
9. Откройте адрес вида `https://имя-пользователя.github.io/portfolio/`.

Все пути в проекте относительные, поэтому сайт работает и в подпапке GitHub Pages.

Проверьте после публикации:

- стили загрузились;
- иконка вкладки видна;
- кнопка резюме работает;
- меню работает на телефоне.
